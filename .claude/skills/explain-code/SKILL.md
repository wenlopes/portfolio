---

Ao explicar código, sempre inclua:

1. **Comece com uma analogia**: Compare o código com algo do cotidiano
2. **Desenhe um diagrama**: Use arte ASCII para mostrar o fluxo, a estrutura ou os relacionamentos
3. **Percorra o código**: Explique passo a passo o que acontece
4. **Destaque uma pegadinha**: Qual é um erro ou equívoco comum?

Mantenha as explicações em tom de conversa. Para conceitos complexos, use múltiplas analogias.
